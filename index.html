Features

🗺️
Geo visualization
Auth failures plotted on a Leaflet map and a Cobe globe with country-level clustering and heat bands.
⚡
Streaming event feed
Server-Sent Events pipeline delivers new failures in real time. Anomaly scoring fires inline on ingestion.
🚫
IP & geo blocking
One-click IP block or country-level geo block with optional expiry. Blocks enforced at the Worker edge.
🔬
Deep IP probe
AbuseIPDB enrichment + reverse-lookup for any suspicious IP, surfaced directly in the dashboard.
📊
Heatmap & analytics
Attack frequency heatmap by day-of-week and hour. Per-route breakdown, failure reason distribution.
🔗
Shareable snapshots
Generate a time-limited public share link exposing aggregate stats — no raw IPs, no admin access required.
🤖
AI threat summary
Workers AI generates a plain-language threat-intel report from recent failures, cached for 5 minutes.
🗃️
Export & backfill
CSV/JSON export (capped at 10k rows). Geo backfill endpoint resolves historic events missing coordinates.

Stack

Cloudflare Workers D1 (SQLite) Hono TypeScript Next.js 15 Leaflet Cobe Globe Workers AI AbuseIPDB Server-Sent Events

Architecture

Auth failures are ingested through a Cloudflare Worker, stored in D1, and streamed to the dashboard over a Server-Sent Events connection. Geo coordinates are resolved on ingestion via a Zippopotam + Census fallback chain and cached in KV. Blocking rules are written back to D1 and enforced by middleware on every incoming request — no external firewall required.
